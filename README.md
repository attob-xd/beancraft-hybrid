# beancraft-hybrid

EaglercraftX 1.8.8 with the 1.18.2 flattening engine, per-section palette, tags, and ~309 of 994 blocks. Connects to a 1.18.2 server through ViaVersion.

Built from `eagle-backport-1.18.2` (WASM-GC target). This is a work-in-progress port, NOT feature-complete 1.18.2 - no swimming, new camera, world height, new generation, or new menu yet. beancraft (the crewmate/high-poly-skins client) is a separate repo and is unaffected.
